# 决策因素优化：审查与执行计划

日期：2026-10-13。依据：[用户提案](../specs/2026-10-13-laya-decision-factor-attribution-design.md)。2026-10-14 用户已授权远端执行；固定权重诊断、两组完整训练及最终评估均完成，结果见[执行报告](../../../reports/laya-decision-execution-20261014-v1/README.md)。主比较控制 96.64%、随机窗口 96.44%，N4 未达成功条件，未自动追加训练。

## 审查结论

- [必须修复] 98.60% 是已观察的 26 份预测的 oracle 准确率：每条样本事后用真值挑选正确模型。它不是可部署融合器成绩，也不限制新模型。96.96% 到此值相差 **1.64pp**；提案的 1.24pp 算术不成立。35 条共同错误不等于标签错误；不能据此保证可回收空间。
- [必须修复] 上游 0.4.1 的 `DecisionModel.forward` 在 encoder 后还有 Transformer `head`，选项表示已通过注意力发生交互。独立的是最后 `scorer(m)`；N1 的准确表述是“增加显式集合条件打分”，不是“首次引入选项交互”。二分类的两两余弦相似度对两选项相同，单独加到分数上不会改变排序。
- [必须修复] EXP-3 原定义同时改变训练输入和推理输入，无法声称唯一变量。两组都导出前缀、首尾，**首尾对首尾**为训练因素的主对照；前缀对前缀为辅助对照，跨视图比较仅作系统结果。
- [建议修改] F2、F5–F8 未给出完整输入清单与重算程序；本轮不将这些数字升级为新的已复核结论。F6、ECE 和共同错误不足以排除 CE、encoder 或其他超参瓶颈。
- [必须修复] `predict_batch` 的批处理仍随视图数增加计算；N6 只减少未截断样本的冗余前向。报告实际次数、窗口数、耗时，不能写成边际成本为零。
- [必须修复] “开发集只读一次”与 EXP-3 按第一轮开发成绩早停冲突；本轮固定两轮与最终轮主评估，不以开发集早停或选择窗口。保留每轮 checkpoint/训练损失，可事后诊断，不能用它选最终模型。

## 已授权实施范围

1. 新增固定权重诊断入口，使用预声明 `baseline-s43` 与 `combined-s42`。核验权重、manifest、划分与 tokenizer；校准 400、开发 2500，官方测试封存。
2. EXP-1：前缀、反序前缀（将输出还原到 negative/positive）、首尾；N2/N6 对超过 466 token 的样本做等权概率平均，其他样本直接复用前缀输出。输出每个单视图、翻转样本、分层指标与精确 McNemar。
3. EXP-2：直接调用锁定上游 `Agent.predict_long`，只推理截断样本，窗口固定 128/256/466、步长为一半。完整保留决定窗口、窗口数和耗时；报告 ECE 时注明原生概率没有整篇校准。三个配置全部报告，不根据开发集选择窗口。
4. N1 先做零梯度诊断：从原 `scorer` 的输入捕获候选表示，使用与集合 mean/max 池化的余弦特征。唯一系数限制在 [-2, 2]，只在 400 校准样本最小化 NLL，拟合并落盘后才读取开发文本。候选自身互换使特征同步互换；这不声称消除了 encoder 的位置偏差。只有校准准确率与 NLL 均改善才具备后续结构训练资格；本轮不绕过门槛训练 N1。
5. N4/EXP-3：新增仅作用于梯度训练的窗口适配器。全长 token 先保留，校准/开发默认仍取前缀；每个训练 epoch 由 seed、epoch、原始 sample ID 的 SHA256 决定 50% 前缀或首尾，不消耗上游 Python/Torch RNG、不改暴露次数/顺序/标签/选项乱序。控制组也使用相同适配器，固定 seed42、strict、FP32、两轮、原学习率和已有 warmup/平滑。
6. N8：提供两个已保存 epoch 的等权参数平均工具，检查键、形状、配置、tokenizer 和 encoder 配置；温度重置为 1，必须在原校准集重新校准后再评估。只生成新目录。

N7 按提案“不建议优先”暂缓；N1 新结构训练和 N8 第二轮内部 EMA 在前置证据成立后另开实验。本轮不改默认部署，不扩大上下文，不搜索学习率或损失，不改原提案和历史报告，不提交 Git。

## 检查与服务器交接

使用 `uv run --offline --frozen`。本地检查覆盖原始 token 的真实尾部、466/467 边界、顺序还原、严格无操作分流、校准拟合隔离、置换等变特征、上游训练函数哈希、控制组编码一致与 RNG 不变、训练 hook 异常恢复、权重平均输入拒绝。测试使用合成文本及 CPU；不启动真实训练或开发集新评估。

服务器执行顺序：配置检查 → 环境/权重准入 → EXP-1/EXP-2/N1 零训练诊断 → 按预声明停止规则决定 EXP-3 → 同期控制及随机窗口两组训练 → 保存权重重载/有限值检查 → 两组统一前缀与首尾最终评估。连接命令和身份信息由用户后续提供。
