# 全序列查询头与稀疏证据选择实验

用户已在讨论全序列情感查询头、DSA 和领域预训练后要求开展实验。本轮先完成可在本机执行的结构筛查，不启动额外付费服务，不修改默认推理入口。

## 假设与范围

固定已经训练完成的 baseline-s43 编码器，提取原始 FP32 全 token 表征。比较均值池化、两个情感查询的稠密注意力、两个查询的 Top-32 稀疏注意力。三种头使用相同参数、初始化、训练顺序和预算，差别仅为聚合权重。主假设为稠密查询头；稀疏查询用于检验证据选择。它们不是 DeepSeek DSA 的复现。冻结编码器的筛查不能替代端到端适配或否定其潜在收益。领域继续预训练不包含在本轮结果中。

## 数据与模型

固定 22100 梯度训练 / 400 校准 / 2500 开发划分，原标签。输入沿用 512、头尾各 233 个评论 token、原两个候选标记、固定候选顺序。仅训练集用于梯度更新。缓存完整有效 token，FP32，不做量化或随机降维。开发文本及预测在全部头、温度、融合权重冻结之后才能读取。始终禁止官方测试数据与预测访问。

头：共享输入 LayerNorm，token 投影 1024→128+GELU，两个原候选标记投影 1024→128 加可学习查询，缩放点积计算权重。均值组在有效 token 上均匀加权；稠密组使用 softmax；稀疏组使用每个查询分数最高的至多 32 个有效 token。聚合结果与查询残差相加、LayerNorm、共享 Linear→1，得到两个候选分数。所有输入有效 token（含题目模板）可被读取，padding 永远屏蔽。注意力作用于输入保留下来的 token，无法恢复截断部分。

## 固定训练与评价

种子 42/43/44；每个头 5 轮，batch 32，AdamW lr=3e-4、weight_decay=.01、dropout=.1、梯度裁剪1，FP32。相同种子的三个头初始权重逐张量相等；每轮相同样本顺序；有限值保护。固定最后一轮，不选择最佳开发或校准轮次。每种头的三个种子分别在校准400上拟合温度[.5,5]，三种子概率均值形成分支。仅校准NLL选择其加入历史97.28%神经融合的权重[0,.25]。主候选预先指定dense，不按开发成绩选择种子或方法。报告所有单种子、三种子均值、融合以及稠密相对均值对照。

评价包括 Accuracy、NLL、ECE、长短分组、修复/新增错误、精确 McNemar、配对分层bootstrap；三种融合候选进行Holm修正。继续扩大实验需净增至少5条（.20pp）、CI下界>0且Holm p<.05；历史重复使用的开发/校准集不称为全新无偏评估。

## 工程验证

新run_id与目录保存协议、源码快照、依赖锁哈希、权重与数据哈希、访问审计、训练记录、缓存索引和冻结记录。提取时逐样本核对历史输入摘要与标记向量差值（允许不同批形带来的FP32误差，阈值1e-3）。单元测试覆盖padding隔离、Top-32稀疏、梯度、同初始状态、冻结边界。最终检查保存/重载预测、独立指标和校准最优解。缓存提取预计数十分钟，本机GPU执行，无网络下载。
