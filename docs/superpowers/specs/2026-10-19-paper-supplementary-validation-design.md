# 论文补充验证方案

日期：2026-10-19。依据用户确认的补实验方向执行，总租卡预算为人民币 100–300 元，上限 300 元。沿用当前工作区，不创建 worktree、不切换分支、不改写历史实验。

## 目标与解释范围

补充重复文本敏感性分析、固定模型的完整开发集后端核验、最终组合的多种子稳定性证据和同平台推理成本。目标是查明证据强弱，不保证得到显著增益或达到某一准确率。

此前已经访问的官方测试和开发数据不会因重划分而恢复独立性。尚无新的独立标注数据；独立确认这一项保持未完成，不用重复训练或扣除重复文本冒充新测试。

## 第一阶段 本地冻结预测分析

复用 `deberta-laya-final-cpu-evaluation-20261018-v1` 的全部 25,000 条冻结预测；保持原始标签和三种模型概率。

1. 完整官方测试：复核原始主结果。
2. 排除与全部原官方训练文本相同的测试记录：包括当前梯度训练、校准和开发来源。移除规则仅由清洗文本决定，不依据预测结果。
3. 测试文本唯一化：按 sample ID 字典序确定每组代表，不挑选预测较好的记录。
4. 同时排除训练侧重叠并唯一化测试文本。
5. 对完整测试和去除重叠后的测试，补充按清洗文本分组、按标签分层的配对 cluster bootstrap，20,000 次，seed 20261019。抽样单位为文本组，同一次抽样共同用于各模型；原行加权口径的分母随抽样组大小变化。

逐组报告 n、类别数、正确数、Accuracy、Macro-F1、AUROC、NLL、Brier、ECE，以及相对 DeBERTa 和 Laya 的修复/退化。行级 McNemar 仅作描述；在存在重复时不将其视为独立样本确认检验。所有补充口径与完整官方测试主成绩分列。

## 第二阶段 本机 CPU FP32 完整开发核验

复用已本地核验的 DeBERTa epoch-002 与原温度 1.1374971945707235。在全部 2,500 条开发记录上重新执行 CPU FP32 推理，比较已有 CUDA BF16 logits、概率、类别及固定 50:50 融合预测。使用原 SentencePiece tokenizer、512 总长度、510 评论长度、255/255 首尾策略、batch 8、12 CPU 线程。

不重新训练、拟合温度或权重；不调用新的测试前向。输入与模型 SHA256、逐样本输入 ID、分块内容哈希及进度持久化；恢复仅接受相同契约及内容。报告不一致样本与结果变化，不以通过有限门槛声称逐位等价。

## 第三阶段 单 GPU 多种子验证

推荐单张 L40S 48GB，Linux、至少 32GB 系统内存、约 150GB 可用磁盘、SSH 登录。沿用锁定环境；Laya 保持 FP32 及非有限值保护，DeBERTa 保持已验证 BF16 训练配方。先核对环境和严格重载，再进行小规模训练测速，不擅自改变有效 batch、输入、轮数或学习率。

完整优先方案为三个系统重复 r=42、43、44；每组 Laya baseline seed=r+1、Laya combined seed=r、DeBERTa seed=r。每组均重新训练三个模型，共九次两轮训练；历史原组合只作为复现参照，不与不同环境新模型混合计算训练方差。

各模型温度在同一原校准集按原流程估计，Laya 内部系数按原 NLL+0.01(λ−0.5)² 规则估计；外层 50:50 固定，不按开发或测试结果改权重、不选最好种子。固定第二轮。报告每组所有模型及融合成绩、三组配对增益的均值、标准差与范围；不把三次相同开发 ID 当作 7,500 个独立样本。

当前多种子主评估限定于开发数据及其文本组分析。最终是否在额外评估数据上评分，须先完成新数据来源及标签质量的独立性核验；不反复用旧官方测试筛选多种子方案。

GPU 运行先估算九次训练与推理所需时长。预计总费用加入磁盘、准备和传输余量后必须不超过 300 元；每个训练任务预留完成及保存时间，到预算边界不启动下一个任务，不在训练中途按成绩停止。若实测无法完成三个完整系统组，明确记录未完成范围，不用只重训 DeBERTa 冒充完整系统多种子验证。

## 第四阶段 同平台成本

在同一台 GPU、相同样本和 batch 下，串行测 DeBERTa 单分支、双 Laya 和最终三模型系统；记录预热、重复次数、总样本数、吞吐、延迟、峰值显存及模型加载是否计入。保持 Laya 长度门控与分支温度一致。评测全部分支的真实前向，不把缓存概率平均时间写成端到端推理时间。

## 远程接入与资产保存

先准备实例配置与每小时价格，脚本就绪后再开机。优先使用专用 SSH 公钥；提供主机、端口和用户名即可，私钥不放入聊天或仓库。平台账户密码不参与连接。实例临时口令如有需要可在本地终端交互输入。

模型、优化器状态和缓存不进入 Git。当前本机约剩 25GiB 可用空间，新训练恢复包优先保留在远端持久盘，回传前核对可用空间；先回传小型日志、预测、清单及 SHA256，不删除现有本地资产。

## 验收

每一阶段使用新 run_id，原始结果和论文主指标不覆盖。核验完成后另生成补充报告，解释哪些风险得到量化、哪些仍未解决；只将实测完成的结果写入论文。
