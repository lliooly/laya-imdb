# CPU 词袋 / NB-ngram 互补性实验

用户明确要求本地 CPU 实验；沿用先前讨论并已授权的 NB 分支设计，不创建 worktree、不切分支、不访问测试分布。

## 固定协议

- 新 run_id：`bow-nb-complementarity-cpu-20261018-v1`。原标签、原始数据和历史文件不改。
- 只用冻结的 22,100 条梯度训练全文拟合词表、频次、IDF、NB 权重和分类器；400 条校准仅拟合下述参数，2,500 条开发在共同冻结后统一评估。
- 两个候选，无超参数搜索：word TF-IDF (1,2) + L2 LR (C=4)；binary NB-weighted word (1,3) + L2 LR (C=1)。min_df=3，max_features=300000，保留否定词、单字符数字和评分形如 8/10，统一 HTML 换行及转义清理。NB 为类内文档频次加一平滑，再按各类总计归一化的对数比。
- 分类器固定 liblinear、tol=1e-5、max_iter=1000、random_state=20261018；若不收敛即停止，不观察开发结果后改变配置。
- 各候选的 sigmoid 校准只用 400 条，拟合斜率 a∈[0.05,20] 与偏置 b∈[-5,5]，最小化平均 NLL + 0.001*((a-1)^2+b^2)。先拟合校准，再拟合融合。
- 原神经分支严格保留旧 Laya 与 DeBERTa 各 50% 的概率。DeBERTa 使用产生开发 97.28% 的 CUDA BF16 缓存，不改成 CPU 版本。
- 各候选分别拟合 p=(1-w)*p_neural+w*p_sparse，w∈[0,0.25]；仅按固定校准集 NLL 最小化，一维凸优化，无向等权收缩。允许 w=0。开发阈值固定 p>0.5。两个候选中以校准融合 NLL 最低者预选主方案，平局按固定候选顺序。
- 不叠加两个稀疏分支，不用开发正确率挑权重、不搜索门控或 stacking，不分析开发正文后改模型。

## 输出与验收

冻结文件包含校准参数、融合系数、主方案、模型及协议 SHA；必须在开发正文 / 缓存加载前落盘。阶段分为 fit / evaluate 两个独立进程，evaluate 不执行拟合。

报告完整开发 Accuracy、NLL、ECE、F1，配对修复 / 退化、精确 McNemar 和 20,000 次类别分层配对 bootstrap。互补性同时给出稀疏分支修复神经错误数与破坏神经正确数、各组的分数方向与长短文分组。标签知情 oracle 仅作上限，不作为可部署结果。全体候选完整报告；反复开发选择、400 校准参数估计和训练随机性不包含在条件样本区间中。

保存 CPU 模型、词表、NB/IDF 参数、环境锁、逐样本预测、校准搜索回执、访问审计、中文 REPORT.md 与 summary.json。检查模型重载预测一致、预测 ID/标签完全对齐、原融合 2432/2500 复现。具有意义的单元测试验证 NB 统计仅由 fit 文档决定、训练/校准/开发隔离、混合权重边界和零权重退化为原预测。
