# Laya 反向差异定位与确定性短程验证

用户已批准按上一条方案执行；继续复用现有 Ghostty 会话，不新建连接、不使用视觉伴侣。正式训练、样本池、历史报告与入口源码保持不变。

沿用四次诊断的锁定入口、完整数据和 5,526 更新学习率预算，所有运行在独立进程中实际更新 16 次后停止，保留原启动开发评估。第一步记录裁剪前每个参数的梯度哈希、模型模块结构，以及第一次前向至反向的 CPU profiler 算子事件计数。参数遍历首个分歧不等于反向时间顺序的首个算子；profiler 增加额外观测扰动。

四组原路径条件各重复两次：默认后端；仅关闭 gradient_checkpointing；仅强制 SDPA math 后端；严格确定性协议。最后一组是显式运行时协议（启动前设置 CUBLAS_WORKSPACE_CONFIG=:4096:8，启用 deterministic algorithms，cuDNN deterministic=true、benchmark=false），不能当作单一算子消融。未支持确定性或 OOM 记录为该条件失败，不降低 batch、长度或精度冒充通过；保留 traceback，不关闭原有限值保护。未知错误立即停止整个流程。

如严格协议的原路径重复一致，追加相同严格协议下控制路径两次短程复验，比较原/控制的完整 16 步。若严格协议失败或漂移，不追加此项；先报告定位边界。最多十次短程、160 更新，不启动全量配对训练，不访问官方测试，不保存模型权重。每 worker 最多 1,800 秒。

默认与变体分别生成新 run_id、环境、配置、trace 和结果，拒绝覆盖历史目录。对首批输入、初始参数、RNG、前向、损失、梯度、优化后参数逐项比较，按参数所属模块统计第一次梯度分歧；实际 profiler 算子支持注意力后端选择判断。独立结果与 manifest 对齐完整分区和学习率预算，先做本地/远端准入测试，再付费执行。预算沿用用户“钱管够”的充分授权，历史 1.24 元/小时仅作参考、当前单价未重验。

通过条件仅为本环境同协议下 16 步逐位一致，不能据此解释历史精度差或宣称全量训练稳定收益。结果传回后逐文件 SHA 校验，完整记录保留供复核。

实现计划：扩展现有可选观测；添加独立运行时协议和矩阵驱动；验证插桩不改变小模型参数/RNG、异常恢复；同步新文件并核验；顺序运行和监控；备份及本地分析。

参考：[PyTorch 确定性算法](https://docs.pytorch.org/docs/2.14/generated/torch.use_deterministic_algorithms.html)、[SDPA 后端](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.scaled_dot_product_attention.html)。
