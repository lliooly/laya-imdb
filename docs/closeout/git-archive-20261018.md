# Git 归档说明

本轮由用户授权补录未提交工作。新增提交从 2026 年 10 月 16 日开始，按研究阶段依次归档至 18 日，作者日期和提交日期使用同一归档时段。该日期用于整理历史，不代替实验实际起止时间；原始日期仍见 run_id、报告、配置和训练记录。已有提交不改写，当前分支保持 main。

## 纳入与忽略

纳入源码、测试、配置、独立环境的依赖锁、设计方案、关键报告与验证收据。忽略数据、权重、恢复包、预测缓存、虚拟环境、日志、编译产物，以及可重建的本机 catalog.json 和 local-assets.json。既有已跟踪报告保持跟踪。

首次检出后，按[复现说明](reproduction.md)先 build 再 verify，以重建本机清单。原始源码资料包是本轮 Git 归档前的独立快照，未覆盖更新。
