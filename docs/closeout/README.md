# 研究与交付总览

更新：2026-10-20。当前版本包含固定异构融合评估、三组完整重训、概率与权重稳健性分析，以及 Word/PDF 最终报告。

## 主要结论

最终冻结方案将双 Laya 多视图分支与 DeBERTa-v3-large 的校准概率等权融合，官方测试 Accuracy 为 **97.028%（24,257 / 25,000）**，Macro-F1 为 0.970280，NLL 为 0.092618，ECE 为 0.650%。相对双 Laya 净增 171 条正确；相对 DeBERTa 净增 24 条，后者 McNemar p=0.1568。

三组完整重训中，等权融合与 DeBERTa 的平均开发 Accuracy 均为 **97.08%**；平均 ECE 从 **1.328% 降至 0.741%**。事后权重诊断观察到小幅增益，但条件区间包含零，尚未形成独立确认或新的部署规则。原 97.40% 开发探索没有对应正式测试成绩。

完整指标、原协议、后端差异及数据使用限制见 [最终结果与工程状态](../experiments/current-status.md)。
