# 项目收尾总览

日期：2026-10-18。本次完成研究材料整理，后续进入最终模型整合、课程报告和视频制作。当前没有启动新训练、追加测试搜索、推送或切换默认模型。

## 主结论与成绩

固定异构融合是本轮最有力的成果：开发 **97.28%**，官方测试 **97.028%（24257/25000）**。相对旧 Laya 主方案测试 **96.344%** 净减少 171 条错误，配对检验显著；这不等于相对 DeBERTa 的增量也同样显著。测试包含既有 Laya CUDA 缓存和新的 DeBERTa CPU FP32，开发使用 DeBERTa CUDA BF16，后端差异如实保留。

最高探索开发候选为 **97.40%**：正则化 logit 融合相对 97.28% 净增 3 条，精确 McNemar p=.25，多重比较修正后不显著，NLL/ECE 变差，没有对应正式测试成绩。它与文献中的 97.40/97.42 不是同一个结果，不宣称 SOTA。

全序列情感查询和 Top32 稀疏聚合已实际训练九个头，没有 Accuracy 收益。结论限于冻结编码器、固定预算；端到端适配和领域继续预训练仍未完成。其他负结果、训练故障、数据修订和未交付权重全部保留。

## 研究协议

- 原梯度训练 22100、固定校准 400、开发 2500、官方测试 25000。修订训练数据另存版本，原标签保留。
- 开发和校准已多次用于研究，官方测试也有历史使用；不称为全项目首次盲评。
- 区分完整覆盖 Accuracy、截断子组 Accuracy 和拒答后的选择性准确率。历史 71 条方案不是 71 次独立训练。
- 比较新增方法时使用相同参照：查询分支 96.84% 与已有融合 97.28% 之间的 0.44 pp，不属于新头增益。
- CUDA Laya FP32 准入、DeBERTa BF16 准入、MLX 类别一致性及精确概率门槛分别认定。

## 整理方式

源代码、配置、日期设计和报告的原路径保留，以维护 import、manifest 和源码哈希。最新入口更新，旧入口原文存入[整理前快照](../archive/closeout-20261018/)。原始报告即使写着“启动中”，也不反向改写；新索引链接其最终 evaluation。完整本地报告只盘点路径与大小，新增指标从既有聚合摘要提取，没有重新评分。

`catalog.json`给出源码、文档、测试、配置和依赖锁的逐文件 SHA；`local-assets.json`仅盘点本地权重位置与大小。权重存在不等于已通过加载，交付结论使用对应原收据。
