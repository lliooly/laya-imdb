## 最终方案与可运行入口

交付研究结论采用测试前冻结的 **双 Laya 多视图分支 + DeBERTa 50:50** 规则：开发 97.28%，官方测试 97.028%。三组重训平均 Accuracy 为 97.08%，与 DeBERTa 持平，ECE 有改善。80:20、校准拟合权重和 97.40% 开发探索均保留为分析候选。

| 入口 | 能力与状态 |
| --- | --- |
| `scripts/predict.py` | Apple Silicon 上的历史单模型预测；开发 95.76% |
| `scripts/predict_laya_fusion.py` | 双 Laya 推理；CUDA FP32 与 MLX 精确 FP32 有既有核验 |
| `scripts/deberta_final_analysis.py` / `deberta_final_evaluation.py` | 冻结研究分析和评估，支持原固定结果的追溯 |
| 随附模型包 `predict_final.py` | 三模型 CPU 单条预测与逐文件哈希已核验；入口、依赖和权重单独交付，不在仓库内 |

视频应明确展示的是训练、单模型演示、双 Laya 推理还是冻结融合评估。已有完整测试证据无需为了展示再次评分。
