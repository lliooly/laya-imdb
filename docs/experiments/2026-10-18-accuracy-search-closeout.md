## 建议

结束当前围绕已固定模型和反复使用开发集的增益搜索，保留新发现的 97.40% 开发候选作为探索结果，开始整理研究报告与交付材料。这个决定基于已测候选的收益规模、成本和证据强度，不是证明不存在更好的结构或全局最优。

## 本轮最后四个候选

主比较统一参照 Laya + DeBERTa 50:50 的 2432/2500 = 97.28%。所有新参数仅用原固定 400 条校准集确定，两个小型 MLP 仅在 22100 条冻结训练表示上训练。共同冻结后才统一评估开发，不读官方测试。

| 候选 | 开发正确数 | 开发 Accuracy | 修复 / 退化 |
|---|---:|---:|---:|
| 正则化 logit 线性融合（校准预选主方案） | 2435 | 97.40% | 3 / 0 |
| 长文加入冻结 2048 分支 | 2432 | 97.28% | 0 / 0 |
| 普通 Dropout MLP 作为辅助分支 | 2431 | 97.24% | 0 / 1 |
| 四次采样 Dropout MLP 作为辅助分支 | 2431 | 97.24% | 0 / 1 |

主方案相对参照净多对 3 条，差 +0.12 个百分点；条件配对 bootstrap 95% 区间 [0.00,+0.28] pp，精确 McNemar p=0.25，四候选 Holm 调整 p=1。原融合 NLL 0.088768、ECE 0.916%，新方案 NLL 0.092339、ECE 1.375%，概率质量变差。不能仅根据没有新增错误或 bootstrap 下界为零宣称统计显著、稳定提升或整体更优。

两个 MLP 单独开发成绩均为 96.84%，预测类别逐样本相同；在当前固定表示、初始化和训练预算下，多样本 Dropout 没有 Accuracy 增益。此结论不外推为所有 Dropout 设置、端到端编码器微调或 attention pooling 无效。缓存只保留候选标记表示，本轮没有足够 token 表示执行全文注意力池化。

新候选实际公式为：

`p(pos)=sigmoid(0.5319458737546259*clip(logit(p_Laya),-12,12)+0.5727065867827512*clip(logit(p_DeBERTa),-12,12)-0.1161031700961201)`。

输入为既有已校准概率；Laya 内部融合和 DeBERTa 原温度保持。参数仅从校准数据拟合，完整系数及校准缓存封存。新候选没有官方测试成绩、没有自动部署。

完整证据：[最后一轮报告](../../reports/final-cpu-alternatives-20261018-v2/REPORT.md)、[机器摘要](../../reports/final-cpu-alternatives-20261018-v2/summary.json)、[独立核验](../../reports/final-cpu-alternatives-20261018-v2/independent-verification.json)。v1 的路径保护误拒绝 sklearn 依赖文件后，v2 仅修正访问保护条件并复用原字节权重，没有重训、重选 epoch 或看到开发成绩后改版本，执行记录单独保留。

## 对外成绩口径

- 正式测试：固定 50:50 异构融合 **97.028%（24257/25000）**，DeBERTa CPU FP32 单模型 96.932%，旧 Laya 主方案 96.344%。新融合相对旧 Laya 的净 +171 条及显著性，不能移用到与 DeBERTa 的比较上。
- 对应原异构融合开发成绩：**97.28%**，使用 DeBERTa CUDA BF16 缓存；开发与测试推理后端不同，数值核对边界保留。
- 新探索候选：**97.40% 开发集**，不是官方测试成绩、不是对文献 97.40% 的复现，也不宣称 SOTA。
- TF-IDF 辅助融合 97.32%、NB 辅助融合 97.28%、校准概率权重融合 97.16%，均保留原记录，不因最新候选更高而删除。
- “71 条”指历史完整开发方案记录，不是 71 次独立训练。两个模型共同错误、融合错误和三流水线共同错误要分别说明，不能把 68 条融合错误都叫共同错误。

正式测试证据：[完整报告](../../reports/deberta-laya-final-cpu-evaluation-20261018-v1/REPORT.md)。开发与校准均已多轮用于研究，官方测试在历史中也已使用，不重新包装为全项目未见数据。
