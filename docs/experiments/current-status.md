# 最终结果与工程状态

更新：2026-10-20。当前版本包括原冻结评估、三组完整重训、权重诊断及最终 Word/PDF 报告。使用入口见 [项目首页](../../README.md)，交付材料见 [交付说明](../closeout/delivery.md)。

## 原固定方案

| 方案 | 开发 / 2,500 | 官方测试 / 25,000 |
| --- | ---: | ---: |
| 双 Laya 多视图融合 | 96.96% | 96.344% |
| DeBERTa-v3-large | 97.04% | 96.932% |
| 固定 Laya + DeBERTa 50:50 | **97.28%** | **97.028%** |
| 正则化 logit 探索候选 | 97.40% | 未评估 |

开发列的 DeBERTa 使用 CUDA BF16；测试使用 CPU FP32，并与冻结的 Laya CUDA FP32 概率缓存融合。完整开发集 CPU FP32 核验中，DeBERTa 为 97.08%，单分支改变 1 条类别，最终融合类别无变化；最大概率绝对差为 0.01190887，后端不逐位等价。见 [后端核验](../../reports/paper-deberta-cpu-development-parity-20261019-v2/REPORT.md)。

固定测试融合的 Macro-F1 为 0.970280、NLL 为 0.092618、ECE 为 0.650%。相对双 Laya，修复 265 条、退化 94 条，净增 171 条正确（+0.684 个百分点，精确 McNemar p≈5.54e−20）；相对 DeBERTa，修复 144 条、退化 120 条，净增 24 条（+0.096 个百分点，p=0.1568）。见 [正式测试](../../reports/deberta-laya-final-cpu-evaluation-20261018-v1/REPORT.md) 和 [独立复算](../../paper/analysis/document_validation.json)。

97.40% 是开发探索成绩，相对 97.28% 净增 3 条、p=0.25；NLL/ECE 未改善，无对应正式测试，不替换最终冻结方案。

## 三组完整重训与融合分析

九次两轮训练组成三套完整系统；全部模型经独立重载、校准、冻结后，在同一开发集评分，保留所有重复。

| 方法 | 第一组 | 第二组 | 第三组 | 平均 Accuracy |
| --- | ---: | ---: | ---: | ---: |
| DeBERTa | 97.00% | 97.28% | 96.96% | 97.080% |
| 原 50:50 融合 | 97.08% | 97.36% | 96.80% | 97.080% |
| DeBERTa 80% + Laya 20% | 97.04% | 97.32% | 97.04% | 97.133% |
| 仅校准集拟合外层权重 | 97.04% | 97.36% | 97.04% | 97.147% |

等权融合相对 DeBERTa 的变化为 +0.08、+0.08、−0.16 个百分点，平均 Accuracy 持平；平均 NLL 从 0.091995 降至 0.089649，平均 ECE 从 1.328% 降至 0.741%，三组 ECE 均改善。见 [完整重训](../../reports/paper-gpu-supplement-20261019-v1/REPORT.md)。

80:20 和拟合权重为事后诊断候选，逐组仅净增 1–2 条正确；三组开发条件区间均包含零。校准集按文本组做五折、重复 10 次，每折重新拟合全部后处理；固定 80:20 保持 DeBERTa 的留出准确率，并降低平均留出 NLL。校准权重对样本组成敏感，没有形成新的最终部署规则。见 [权重诊断](../../reports/paper-fusion-diagnostics-20261020-v1/REPORT.md) 与 [稳健性分析](../../reports/paper-fusion-robustness-20261020-v1/REPORT.md)。

RTX 4090 同平台、64 条固定开发记录、batch=8：DeBERTa 78.576 条/秒，三模型融合 20.683 条/秒，峰值已分配显存分别为 2.447 / 5.586 GiB。计时含分词、传输、前向和融合，不含加载；批处理摊销耗时不能当作单请求延迟。

## 评估限制

原官方训练集划出 22,100 条梯度训练、400 条校准和 2,500 条开发记录；官方测试为 25,000 条。开发、校准与测试均有历史使用，原固定测试不称作全项目首次盲评。原训练/测试有 123 个唯一清洗文本重叠，其中实际梯度训练/测试有 113 个；测试内部有 201 条额外重复记录。见 [重复文本检查](../../reports/paper-duplicate-sensitivity-20261019-v1/REPORT.md)。

三组重复共用同一开发集，不是 7,500 条独立样本；新增补实验没有访问官方测试。条件重采样区间不覆盖全部训练方差、拟合方差和历史研究选择偏差。当前结果支持部分配置的小幅分类增益及概率质量改善，尚不足以断言稳定优于最强单分支。
