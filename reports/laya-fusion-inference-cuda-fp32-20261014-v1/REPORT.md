## 推理成本

RTX4090，PyTorch FP32，AMP／TF32关闭，batch=8。固定使用原校准集前128条，其中17条截断；每种模式2轮预热、5轮测量。单模型阶段只驻留baseline，融合阶段驻留两模型。

| 指标 | 首尾单模型 | 双模型门控融合 |
| --- | ---: | ---: |
| 128条批量请求的中位总耗时 | 1.916秒 | 4.133秒 |
| 吞吐量 | 66.82条／秒 | 30.97条／秒 |
| 每条批量摊销耗时 | 14.96毫秒 | 32.29毫秒 |
| 每轮实际样本前向行数 | 128 | 290 |
| CUDA峰值allocated显存 | 1.91 GiB | 3.48 GiB |
| CUDA峰值reserved显存 | 2.15 GiB | 3.79 GiB |

融合中位耗时约为单模型的**2.16倍**。计时包括分词、输入构造、CPU／GPU传输、前向及概率聚合，排除模型加载；每条摊销值不等于单请求延迟。显存是PyTorch CUDA分配器峰值，包含驻留权重，不是设备全部驱动与其他进程的总占用。

这128条中截断比例为13.28%，不同于完整开发集的16.28%。完整开发融合预计5814个样本前向、单模型2500个，前向行数比为2.33；不能将它与本小批量实测时间比混为同一个指标。原始五次测量、加载耗时、样本IDs和长度见[benchmark.json](benchmark.json)。
