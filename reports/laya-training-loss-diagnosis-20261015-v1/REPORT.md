# 训练共同错题的损失集中度与下一轮干预依据

日期：2026-10-15。状态：仅分析既有预测；未训练、未做新推理、未修改标签，未读取开发或官方测试预测及正文。

## 1. 新发现

94 条共同错题候选占 22100 条梯度训练样本的 **0.4253%**。在旧 baseline-s43 的末期训练集预测中，它们占重算未平滑 CE 损失的 **80.4000%**；在旧 combined-s43 中为 **26.7999%**。筛选集合已从两份预测重新计算，与原 94 条台账完全一致，且两份预测的全部 ID、标签和输入 SHA 已逐条对齐。

| 静态指标 | baseline-s43 | combined-s43 |
| --- | ---: | ---: |
| 全池误判数 | 127 / 22100 | 220 / 22100 |
| 94 条的未平滑 CE 损失占比 | 80.4000% | 26.7999% |
| 94 条的 CE logit 梯度绝对值占比 | 66.5914% | 12.1842% |
| 改用纯 GCE 时的静态梯度占比 | 11.6147% | 1.3716% |
| 改用 0.5 CE + 0.5 GCE 时的静态梯度占比 | 59.4361% | 7.5819% |

**这些是训练结束后的样本内快照，不是整个训练过程的损失贡献，也不是参数梯度范数占比。** 两份预测均为旧 `original_head` 前缀输入、同 seed43，不能作为本轮首尾训练或跨种子复现。combined 实际使用标签平滑，本报告为了统一比较重算未平滑 CE，不能把表中数值写成其真实训练目标的构成。

## 2. 为什么不能直接删除候选或采用强筛除

94 条的现有 AI 工作分类为：58 条标签—文本态度冲突候选、23 条态度不明确、6 条前缀缺少决定性证据、7 条可见模型错误候选。它们均未经独立人工确认为错标。

设给定标签的概率为 `p`，GCE 为 `(1-p^q)/q`，取 `q=0.7`。其梯度等于 CE 梯度乘以 `p^q`。在 baseline 快照中，58 条冲突候选的该因子中位数为 **0.00903**，7 条可见模型错误候选则为 **0.00209**。因此纯 GCE 同样会强烈压低真正困难样本的学习信号，不能将其解释为识别出了错误标签。

建议将 **0.5 CE + 0.5 GCE** 作为一个保守候选：梯度相对 CE 的乘数为 `0.5+0.5*p^0.7`，处于 `[0.5, 1]`，保留所有原始样本和标签。这仍会降低困难样本的权重，是否有利必须通过新训练测量；不能由静态表格推断准确率收益。

GCE 是已有方法，公式、梯度关系及鲁棒性与可学习性的权衡见 [Zhang 与 Sabuncu，NeurIPS 2018](https://papers.nips.cc/paper/2018/file/f2925f97bc13ad2852a7a551802feea0-Paper.pdf)。原文实验主要采用图像数据和合成噪声，其结果不是 Laya / IMDB 的收益证据。混合比例 0.5 是本轮预先选择的保守设置，不是原文给出的 IMDB 最优值，也不构成本项目的原创方法声明。

## 3. 精确计算口径

从两份导出的每行双类别 logits，用稳定 log-softmax 取得原标签概率 `p`。按原规则取两模型均错且错误类别相对原标签的 logit margin 均大于 1 的交集；核对其恰好等于台账的 94 个 ID。

逐条计算：

- CE 损失：`-log(p)`。
- 纯 GCE 损失：`-expm1(0.7*log(p))/0.7`。
- 关于二分类 logit 差的 CE 梯度绝对值：`1-p`。
- 纯 GCE 梯度绝对值：`p^0.7*(1-p)`。
- 混合梯度绝对值：`(0.5+0.5*p^0.7)*(1-p)`。

表中占比均为所选 94 条的相应数量之和除以全体 22100 条的和。全部计算使用 float64；组内中位数逐条计算后再取中位数。二分类两个 logits 的梯度 L1 范数同时增加常数因子 2，不改变占比；不同样本经过模型 Jacobian 后的参数梯度可能相互抵消，此处没有估计这种作用。
