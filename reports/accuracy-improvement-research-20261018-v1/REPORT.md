# IMDB Accuracy 还能提升多少、该怎么优化：证据综合报告

- **日期**：2026-10-18（北京时间）
- **run_id**：`accuracy-improvement-research-20261018-v1`
- **性质**：研究分析与路线建议。**本轮没有训练、没有新增推理、没有读取官方测试逐样本**；只使用本地冻结的开发/校准预测、已归档报告中的测试聚合计数和公开文献。
- **团队产出**：本文件为合成报告；支撑分析见同目录 [headroom-analysis.md](headroom-analysis.md)（剩余空间定量）、[literature.md](literature.md)（文献与标签噪声）、[experiment-plan.md](experiment-plan.md)（可行性与实验计划）、[verification.md](verification.md)（独立复算，63 项检查 62 通过、0 失败、7 条措辞/口径差异）。
- **一句话结论**：**全覆盖 98% 在现有数据、预算和测试封存规则下基本不可达；当前 97.028% 已接近公开可核验上限，也接近人工验证的测试标签噪声上限。剩余可实现的提升约为 +0.1~0.3 个百分点，且必须来自"新的模型/训练信号"，不是融合、窗口、校准或后处理。唯一已有实测证据的"98%+"是选择性分类：官方测试实际覆盖 88.93% 时保留准确率 99.23%。**

## 0. 结论速览

1. **现状**：冻结的 Laya+DeBERTa 50:50 异构融合在官方 25k 测试上 **97.028%（24,257/25,000）**，开发集 97.28%（2,432/2,500）；探索性开发最高 **97.40%（2,435/2,500，p=0.25，不显著）**。正式测试 Wilson 95% 区间 [96.81%, 97.23%]。
2. **距 98% 的距离**：开发需净多对 **18 条**（68 条错误的 26.5%）；官方测试需净多对 **243 条**（743 条错误的 32.7%）。考虑开发—测试约 0.25~0.6 pp 落差，测试 98% 可能要求开发达到 98.25~98.6%。
3. **剩余错误不是"没训够"**：68 条开发错误中，47 条是三条流水线共同错误；**仅 7 条有明确文本证据支持标签**（其余 11 条强标签冲突、46 条评价歧义/反讽/评价轴错位、1 条截断、3 条不确定，均为 AI 定性）；29/68 条融合置信度 ≥0.95，截断只解释个位数错误。
4. **后处理已饱和**：57 个去重冻结视角的标签知情 oracle 为 99.24%，但**所有只用 400 条校准集拟合的等权/ridge/多数/门控规则最高只有 2,435（+3，p=0.25，区间下界 0）**；两模型（Laya+DeBERTa）oracle 只有 **97.88%**——即使完美选择当前两个模型也到不了开发 98%。**必须引入新的独立模型或训练信号。**
5. **公开文献与标签噪声**：官方 25k/25k 可核验的公开最好成绩约 **96.80%（XLNet-large，NeurIPS 2019）/ 96.54%（RoBERTa-large，2024）/ 96.68%（额外使用 50k 无标注+LLM 伪标注）**；更高声明均存在协协议问题或已被纠错。cleanlab + MTurk 对 IMDB 测试集的人工验证错标率为 **2.90%（725/25,000，其中 173 可更正、552 无法达成一致）**，按"噪声不可学习"的简单上限约 **97.10%**——本项目 97.028% 距该上限仅 **18 条**。该上限是估算而非证明，但方向一致：98% 全覆盖需要"复现"至少数百条被人工判为错标/歧义的样本。
6. **优化建议**：
   - **若目标是课程/论文交付（推荐）**：停止增益搜索，采用 97.028% 全覆盖 + 99.23%/88.93% 选择性分类 + 误差结构与标签噪声分析 + 负结果清单；98% 写成研究志向并给出证据。
   - **若目标是继续提高全覆盖 accuracy**：按 §4 的预声明路线做一次（优先新异构模型或领域继续预训练），预期开发 97.5~97.8%、测试 97.1~97.5%，**仍达不到 98%**；本地耗时约 4~20 小时，无付费 GPU 预算。
   - **若 98% 是硬指标**：只能以"覆盖率 + 准确率"口径交付（88.93% 覆盖、99.23%），或换数据/评测协议（本项目的数据封存纪律下不可接受）。**不应通过按测试结果调参、改融合权重或声称 98% 已达成来实现。**

## 2. 三个独立证据：为什么"再优化 1 个百分点"很难

### 2.1 误差结构：剩余错误主要是标注/语用歧义，不是模型训练不足

对开发集 68 条融合错误做了逐条审计（全文 + 概率/置信度 + 截断标记；AI 定性，非人工独立裁定）：

| 类别 | 数量/68 | 例 |
|---|---:|---|
| (a) 标签—正文冲突候选（正文有作者自评分/总评与标签相反） | **11** | H006（neg 标签但全文 "Great movie"）、H034（pos 标签但 "4 out of 10"） |
| (b) 评价歧义/反讽/评价轴错位（烂但好看、价格反讽、系列 vs 本片） | **46** | H002 价格锚定挖苦、H027 "制作烂但看得开心"、H036 类型片"烂得值得看" |
| (c) 截断缺失关键证据 | **1** | H026 |
| (d) 文本支持标签的明确模型误判 | **7** | H001 系列好评干扰当前差评、H018 明确贬损却判正 |
| (e) 不确定 | **3** | 叙事/自述，无法单极化 |

其它事实：

- 68 条中 47 条属于"三流水线共错"（旧 Laya 主融合、2048 视角、DeBERTa 同时错），21 条是融合特有；49/68 至少被一个现有视角答对，**19/68 在全部 57 个视角中全错**（这 19 条以标签冲突/强歧义为主）。
- **置信度不低**：68 条中 29 条融合置信度 ≥0.95、36 条 ≥0.90，中位数 0.9198。不是"只差低置信度样本"。
- **截断不是主因**：Laya 侧截断 10 条、DeBERTa 侧 8 条、双截断 8 条；"截断缺失关键证据"仅 1 条。已发表的长短分组也显示截断组并不更难（融合截断组 97.54% vs 未截断组 97.23%）。
- 68 条中 57 条涉及标签或评价歧义，只有 7 条是"文本清楚、模型判错"。**继续加头、加窗口、加长输入的期望收益只能按个位数样本估计。**

### 2.2 冻结预测池与融合饱和：后处理取不出 oracle 的余量

| 证据 | 数值 | 含义 |
|---|---:|---|
| 冻结开发视图记录 → 去重后互异预测向量 | 85 → **57** | 池子很大，但大量同权重/同模型导出 |
| 经典 18 视角（22 文件）标签知情 oracle | **2,460/2,500 = 98.40%**，40 条全错 | 与历史文档完全一致 |
| 扩大池 57 视角 oracle | **2,481/2,500 = 99.24%**，19 条全错 | 仅含单模型/单分支池也是 2,481；**标签知情事后上限，不可部署** |
| **两模型（Laya+DeBERTa）oracle** | **2,447/2,500 = 97.88%** | **即使完美选择当前两个模型，开发 98% 也不可达** |
| 400 校准集上所有等权/ridge/多数/门控规则 | 最高 **2,435**（+3，p=0.25，CI 下界 0） | 融合权重空间已饱和；L2=0 变体只有 2,434（对拟合细节敏感） |
| 校准集拟合的乐观性 | 校准重代入准确率 98.8~99.0%，开发只有 97.28~97.40% | 校准集比真实泛化乐观约 +1.4 pp |
| 98% 所需净修正（开发） | 2,432 → 2,450，**+18 = 68 错的 26.5%** | 若从 2,435 起则 +15 |
| 98% 所需净修正（官方测试，聚合） | 24,257 → 24,500，**+243 = 743 错的 32.7%** | 测试侧需要修复约三分之一的现存错误 |
| 已观测互补捕获率 | 两模型 oracle 相对主融合 +23 条，实际融合只拿到 +8（约 35%） | 弱视角（NB 91%、TF-IDF 91%、pilot 94%）能救 27/22 条错题，但与强融合翻转率 7~8%，固定权重只回收 1 条左右 |

**正确读法**：oracle 99.24% 只说明"现有输出里还留着标签可区分的正确信息"，不代表存在可部署规则能取出来。实际可部署的组合全部停在 2,431~2,435；从 2,435 到 2,450 需要捕获 46 条可修复余量中的 32.6%（或 49/68 可修复池的 36.7%），而历史捕获率约 35% 且只对弱相关视角成立——这正说明**需要新的、强而独立的模型，而不是继续调融合**。

### 2.3 公开文献与标签噪声：97.03% 已在公开上限附近

**可比公开成绩**（官方 25k/25k；详见 [literature.md](literature.md)）：

| 方法 | 官方测试 Accuracy | 说明 |
|---|---:|---|
| XLNet-large（2019） | **96.80%** | NeurIPS 2019 proceedings Table 4；arXiv v1 旧值为 96.21 |
| RoBERTa-large（2024，LlamBERT） | **96.54%** | preprint，全测试集 |
| RoBERTa-large + 官方 50k 无标注 + LLM 伪标注 | 96.68% | 使用额外无标注数据与 LLM 标注 |
| PWC 2025-06 榜单最高（自报） | 96.68% | PWC 已停服，经 CFA 论文 Table III/镜像恢复 |
| 本项目 Laya+DeBERTa 融合（本地） | **97.028%** | 训练样本更少（22.1k），但测试非独立、开发反复使用 |

> 声称更高的结果均需打问号：97.42%（dv-cosine）因隐式使用测试标签被公开更正为 **93.68%**；97.67%（BERT+BiLSTM）公开实现合并官方 train/test 后重切（约 62% 官方 test 进入训练）；97.072%（CFA 异构集成）按测试表现选组合/超参；98.12%（SentimentBERT）未报告官方 25k/25k 协议。准确表述是：**没有找到经验证的、协议一致且可独立复现的全测试 ≥97.0% 公开结果。**

**标签噪声**（本报告的关键约束）：

- cleanlab + MTurk 对 IMDB **测试集 25,000 条**做 confident learning 候选挖掘与人工验证：CL 标出 1,310 条候选，人工确认 **725 条错标 → 2.90%**；其中仅 **173 条（0.69%）** 可明确更正，**552 条（2.21%）** 连 5 名标注者都无法就正确标签达成多数。来源：[Northcutt et al., NeurIPS 2021 D&B, arXiv:2103.14749](https://arxiv.org/abs/2103.14749) Table 1/2（2026-10-18 由 literature-scout 重新核对）。
- 按"这 725 条对任何文本模型都不可学习"的简单上限：1 − 725/25,000 = **97.10%**。本项目 97.028%（743 错）**只比该上限多 18 条错误**。该上限是算术估算而非数学证明（部分"歧义"标签可能被模型偶然命中），但它与本地证据方向一致。
- 本地训练池：94 条高置信共同误判经用户逐条人工裁定，**61 条翻转、23 条保持、3 条删除、7 条待定**——即"模型高置信判错的训练样本"中约 **65%** 被确认是标签问题（cleanlab 候选中的错标率约 55%，方向一致）。61 条翻标重训在 Laya 上只带来 +0.08 pp（p=0.88，不显著），因为**评测标签仍是评分代理标签**，清洗训练标签改善的是"真实语义"，不等于提高官方指标。
- 因此 98% 全覆盖意味着：要么模型"复现"至少约 225 条被人工判为错标/歧义的样本（在 725 条上限下几乎不可能），要么真实标签噪声比 2.9% 低约 1 pp——现有公开证据不支持后者。

## 3. 进步空间：分层回答"还有没有空间"

| 目标口径 | 是否还有空间 | 量级 | 需要什么 |
|---|---|---|---|
| **全覆盖官方测试 98%** | **基本没有（本地/现有数据下不可达）** | 需 +243 条（现有错误的 32.7%） | 换模型/换训练范式/换数据或测试口径；不是后处理能解决 |
| **全覆盖开发 98%** | **很小** | 需 +18 条；两模型 oracle 仅 97.88%，后处理实测上限 97.40% | 至少一个**强而独立**的新模型/新训练信号；最好状态 dev 97.5~97.8% |
| **在 97.0% 上小幅提升（dev/test）** | **有，但有限** | +0.1~0.3 pp | 新异构模型（如第二个 DeBERTa seed/新家族）或 DAPT/TAPT；成本 4~20 小时本地 |
| **语义准确率（按人工修正标签）** | **可能有空间** | 未知；现有标签噪声会同时压低训练与评测 | 独立人工复核/更干净的标签来源；不能改变官方测试标签 |
| **高精度 + 部分覆盖（≥98%）** | **已实现** | 测试 99.23% @ 88.93% 覆盖；开发 98.84% @ 90% | 校准集定阈值 + 拒答/人工复核流程；必须报覆盖率，不能当全覆盖 |

**一句话**：如果把"accuracy"定义为官方测试集 100% 覆盖的正确率，**剩余空间的上限是 +0.1~0.3 pp，不是 +1 pp**；如果把"accuracy"定义允许拒答/人工复核的部署场景，**98%+ 已经由既有测试证据达到**。

## 5. 如果目标是课程交付（推荐路径）

**结论：现在收尾是最优决策。** 继续投入 4~20 小时最多把 test 从 97.03% 提到约 97.1~97.5%，无法达到 98%；而现有证据已足够支撑一份有深度、诚实的研究报告。

### 5.1 建议写进报告的核心结果

1. **主成绩**：官方 25k/25k 全覆盖 **97.028%（24,257/25,000）**，Wilson 95% [96.81%, 97.23%]；相对旧 Laya 主方案净 +171 条（+0.684 pp，McNemar p≈5.5e-20，CI [+0.536,+0.832] pp）。DeBERTa 单模型 96.932%、旧 Laya 96.344% 作为参照。
2. **部署场景结果**：用 400 校准集定 90% 覆盖阈值，在测试集**实际覆盖 88.93% 时保留准确率 99.23%**（22,062/22,233）；明确写"非全覆盖"。
3. **诊断结论**：68 条开发错误中 47 条三流水线共错、49 条可被某视角救但无规则可提取、19 条全视角全错；错误以标签冲突/评价歧义为主（AI 定性 11/46/1/7/3）；截断只解释个位数。
4. **负结果**：warmup+LS、R-Drop、稳健损失、重采样、语义增强、随机窗口、权重平均、头部对照、查询头、长度路由、长文融合、校准权重等全部未过门槛——这是研究价值，不是失败。
5. **98% 的定位**：研究志向未达成。三条最有力论据：① 公开可核验的协议一致 SOTA 约 96.8%，无 ≥97.1% 的可信结果；② 测试集人工验证错标率 2.90%，隐含上限约 97.10%，本项目差 18 条；③ 两模型 oracle 仅 97.88%，后处理实测上限 97.40%。
6. **局限**：官方测试非独立（历史已用）；开发集反复使用；oracle 为标签知情上限；错误分类为 AI 定性；部分第三方文献数字未独立复现。

### 5.2 建议的对外表述模板（可直接改写进 Word 报告）

> 本项目在 IMDB 官方 25k/25k 测试集上取得**全覆盖 97.028%**（24,257/25,000）的冻结异构融合成绩；在此之上，使用仅由 400 条校准集确定的拒答阈值，在**实际覆盖 88.93%** 的样本上保留准确率达到 **99.23%**。98% 全覆盖目标未达到。公开文献中尚无经验证、协议一致且可独立复现的全测试 ≥97.1% 结果；同时人工验证显示 IMDB 测试集约 2.90% 标签存在争议，隐含上限约 97.10%。因此本文把 98% 作为研究志向而非已达成绩，并系统报告了失败方向与误差结构。

## 8. 本报告没有证明什么

- 没有证明"98% 在原则上不可能"：它只是说明在**固定数据划分 + 官方测试 + 现有公开证据/本地预算**下不可达；换更大模型、更多数据或修正标签后未必如此。
- 68 条错误的 AI 定性分类不是人工独立裁定；11 条"强标签冲突"也不是已确认错标，不能据此改开发/测试标签。
- oracle 数字是标签知情事后上限，包含近重复/事后组合/被多轮开发选择的视角，不能作为方法可达上限。
- 外部文献数字为作者自报，本轮未复现任何文献训练；cleanlab 的 2.90% 是经过人工验证的下界估计，"97.10% 上限"是本报告的算术。
- 本轮没有新训练、新推理；所有 P1~P4 预期都是估计，不是已验证收益。
