# 共同错题人工初筛

Mac 两轮基线与 4090 四组 seed=42 模型共有 47 道错题，20 条负面、27 条正面；40 条未截断、7 条长文被截断。逐条初筛见 review.csv。

类别是候选解释，并非已证明的模型失误原因。疑似正文标签冲突不能视为已确认标注错误；固定验证集和标签保持原样。狮子王续作样本的明确负面结论在长篇剧情之后，需要进一步核查实际编码窗口。

先完成 seed=43 原基线与 warmup+平滑的成对复验，校准划分保持 seed=42。逐轮权重独立验证，主指标仍为最终两轮模型。第一轮与第二轮的变化用于判断过拟合，单独选出的最好轮次仅作次要诊断。

复验后再考虑从训练集筛选褒贬混合、反讽及低质量但喜欢的样本做增强，不把验证错题复制进训练。不访问官方测试集。
