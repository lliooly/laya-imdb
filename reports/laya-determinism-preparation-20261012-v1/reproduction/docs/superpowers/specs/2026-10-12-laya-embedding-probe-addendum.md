# 嵌入层算子复验补充

默认路径两次重复的首个梯度分歧只涉及 205 个参数中的 token embedding 矩阵（50368×1024）。首步 profiler 还观察到 Triton 编译的 embedding/LayerNorm 及其反向融合内核；这使嵌入梯度累加优先于注意力成为复验对象。原矩阵继续按原协议执行，不修改正在运行的代码。

新增三次独立进程的小型算子复验，分别为 ModernBertEmbeddings 编译路径、eager 路径和严格确定性编译路径。读取相同冻结 encoder/config.json 配置，不读训练数据或模型权重；以 seed=43 新建随机嵌入层和合成 8×512 token ID（范围 0..1023，制造重复 ID）、固定 8×512×1024 上游梯度，每个条件反向重复四次。复验复用已安装 Transformers 的实际 ModernBertEmbeddings 实现，记录输出、RNG、每个参数梯度哈希及与首轮的差异元素数和最大绝对差值。

这些合成输入只能验证候选算子在对应配置下的行为，不能替代真实首批输入/上游梯度的因果复验。各进程最多 180 秒，原矩阵退出后顺序执行，不同时抢占 GPU，不启动完整训练。保留 profiler 首次编译事件差异，检查重复输出和梯度而不要求首轮编译事件计数与热缓存轮相同。
