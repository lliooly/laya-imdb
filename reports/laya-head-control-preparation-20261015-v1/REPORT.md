# L2 头部对照准备报告

日期：2026-10-15。状态：**设计与只读核验完成，待审阅；没有开始实现或训练。** 正式规格见 [同期头部对照设计](../../docs/superpowers/specs/2026-10-15-laya-head-control-design.md)，核验数据见 [summary.json](summary.json)。

## 1. 本轮结论

L1 已说明固定编码器表示能被简单读出，但不能识别联合训练中原头的贡献。L2 推荐从相同的 Laya 发布编码器起步，原架构头与共享线性头均重新初始化，在 seed42、43、44 上配对重训，共六次。固定两轮、同一首尾输入、同一优化配方和同一最终轮，避免混合权重起点、输入变化与选模差异。

三个 seed 是初步估计训练变化的预算，不足以预先承诺跨 seed 显著性或非劣效。正式报告应同时呈现样本条件区间和逐 seed 的配对差，不能把同一批 2,500 条样本重复三次当作 7,500 个独立观测。

## 3. 设计中处理的关键混杂

### 3.1 保留预训练原头会混入初始化优势

若控制组继承发布的原头，线性组重新初始化，差异同时包含头部结构和预训练头权重。推荐两组都重新初始化，保留同一编码器起点；因此新的 original 也不是原 baseline 的复现，历史 96.84% 不作为同期控制。

发布配置本身记录已有 7,313 次更新，编码器已经参与 Laya 联合训练。新对照只能对这个共同起点及指定训练预算作判断，不能宣称得到了与头部无关的原始 ModernBERT 表示。

### 3.2 “同一个 seed”需要明确各随机流

上游样本 shuffle 与选项排列已各用独立 Python RNG，可以保留；Torch 训练 RNG 在循环开始重置。新头构造必须显式设置独立初始化 seed，并记录状态哈希，不能依赖加载器的隐式随机消耗。

源编码器的声明 dropout 均为 0。实际模块配置仍需在实现准入核对。原头自己的 dropout 属于原架构；不要求两种不同结构消耗同样多的随机数，只要求数据输入成对相同、各条件自身复验满足协议。

### 3.3 上游保存会量化到 FP16

`laya.train.save_checkpoint` 对状态无条件执行 `.half()`。本设计要求训练和主评估均使用 FP32，因此新入口须独立保存 FP32、重载并验证，再拟合温度；不能只根据训练时 AMP=False 宣称最终评估的是 FP32 训练状态。

### 3.4 现有窗口入口并非通用多 seed 入口

`train_laya.py` 的窗口配置验证绑定 seed42、strict CUDA 和特定配方，现有窗口适配器也不直接支持固定 head_tail 训练。本轮不放宽历史验证条件，规格要求新增独立 L2 入口，复用受保护的上游训练循环与数值保护。

## 4. 推荐的固定实验矩阵

| 条件 | 初始化 | seed | 输入 | 训练与主 checkpoint |
| --- | --- | --- | --- | --- |
| original | 同源 encoder＋新原架构头 | 42、43、44 | 训练 / 校准 / 开发均首尾 | 两轮，第二轮唯一主模型 |
| linear | 同源 encoder＋新共享线性 scorer | 42、43、44 | 与成对 original 逐条一致 | 同预算、同选模规则 |

每组每 seed 共 5,526 次更新，六次共 33,156 次更新、265,200 次梯度样本曝光。无 warmup、无 label smoothing，不增加增强或难例重采样。两种结构分别约 4.2103 亿和 3.9478 亿可训练参数，参数少不直接等于同比例提速。

六次全部训练、FP32 重载和 400 条温度校准完成并冻结后，才读取开发正文进行统一评估；不得在完成第一对后看开发差值，决定是否改头、换学习率或追加训练。

## 5. 不确定性与决策边界

主方向为 original−linear。报告三个单独配对差、均值、样本标准差、范围及留一 seed 均值范围。固定六个模型的样本 bootstrap 必须联合重采样相同 ID，并明确不覆盖训练 seed 和校准拟合变化；截断的 407 条开发样本另报。

三个非零配对差即使全部同向，对称符号翻转下最小双侧 p=0.25。本轮不把“固定模型样本区间很窄”写成“跨 seed 已证明显著”，也不把区间含零写成等价。0.20 pp 仅作下一步投入的实用参考尺度；具体分支已写入设计，不自动部署或扩 seed。

官方测试此前已使用，本轮不会再次用它调参或确认新候选；这些结果仍受开发集历史复用的限制。
