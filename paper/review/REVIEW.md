## 高风险

### H1 官方测试存在历史反馈，无法充当全新独立确认集

- 位置：原第 1 节、第 6.2 节，第 45、266 行。
- 证据：原文明示官方测试已用于历史研究；本轮在新评分前固定候选只能约束本轮操作，不能撤销此前测试信息的影响。
- 影响：97.028% 是固定官方测试上的可复核观察值，但相应区间和 p 值不能覆盖历史反馈与适应性选择造成的偏差。不能将其升级为“全程从未接触测试集”的独立确认结果。
- 状态：**既有风险，文字修订无法消除。** 已将限制集中到第 6.2 节，并在摘要保留简短说明。进一步确认需使用未参与研究选择的独立数据。

### H2 实际梯度训练与官方测试存在相同文本，且测试内部有重复

- 位置：原第 2.1 节、第 6.2 节，第 68、266 行。
- 证据：原文仅报告原始官方训练/测试间 123 个唯一清洗文本交集。按真实训练 manifest 的 22,100 个梯度训练 ID 重算，有 **113 个相同清洗文本，对应 113 条测试样本**；测试内部另有 **201 条重复额外记录**。实际梯度训练与校准、开发的清洗文本交集均为 0。
- 影响：部分测试文本在参数学习阶段出现过；测试内部的同文样本也并非相互独立。未经文本分组处理的样本区间可能低估相关性。这来自数据与划分事实，不能据此认定人为作弊，也不能直接推算成绩被抬高多少。
- 状态：**既有数据风险，披露已补全。** 保持完整官方测试分母及原始主成绩。若后续补充去重敏感性分析，应与官方主成绩分列，不能替换分母后继续沿用 97.028% 的名称。
- 复算证据：[audit.json](audit.json) 的 `duplicate_audit`；可运行 `audit.py` 复核，受影响测试 ID 已保存。

## 中风险

### M1 开发集与校准集多轮复用，局部校正不能覆盖整个研究的选择偏差

- 位置：原第 2.2、4.2、6.2 节，第 74、144、266 行。
- 证据：同一 400 条校准样本用于温度、内部融合系数、其他后处理对照及拒答阈值；同一 2,500 条开发集用于多轮比较。Holm 校正只分别覆盖六组历史比较和四个融合候选。
- 影响：一次拟合没有读取开发标签，并不使整个研究重新拥有独立开发集；局部调整后的 p 值也不能代表全研究的确认性显著性。
- 状态：**原文已披露的风险。** 已保留选择偏差说明，补充 bootstrap 次数、随机种子及固定模型的条件解释；没有把校准集复用写成梯度训练泄漏。

### M2 异构融合尚未证实稳定优于最强单分支，最终组合也缺少多种子确认

- 位置：原摘要、第 5.2、6.2、7 节，第 37、170、266、295 行附近。
- 证据：相对 DeBERTa，最终融合修复 144 条、退化 120 条，净增 24/25,000，即 0.096 个百分点；精确双侧 McNemar **p=0.1568**。相对 Laya 的 171 条净增量来自另一比较。最终三模型组合仅有一组固定模型身份，三种子头部/损失实验不能替代该组合的训练方差估计。
- 影响：可以说融合改善当前 Laya 系统，也可以描述其对 DeBERTa 的观察差值；尚不能说“已证明稳定优于最强单模型”。融合 AUROC 为 0.994350，略低于 DeBERTa 的 0.994449，也不能声称所有指标最优。
- 状态：**原结论基本正确，属于证据范围风险。** 修订版将最强单分支比较直接放入结论，保留 p 值，减少重复的防御性表述。

### M3 方法主线清楚，但若只读正文，若干关键复现细节缺失

- 影响：中文意译问题模板、改变训练视图或将 512 全部留给评论，都可能改变实际输入和输出。流程图及公式本身正确，缺陷在于正文尚不能充分限定同一实现。
- 状态：**已补充。** 依据实际源码、配置、保存的温度及训练/评估记录写明上述信息；未重新拟合温度、权重或其他参数。

### M4 开发与测试的 DeBERTa 后端不同，有限准入不能证明全量等价

- 位置：原第 3.3、6.2 节，第 104、269 行。
- 证据：开发为 CUDA BF16，测试为 CPU FP32。实际准入仅覆盖 400 条校准与 128 条开发样本，类别差异均为 0；最大概率绝对差分别为 0.0041705821 和 0.0059585890。
- 影响：有限样本类别一致不能排除其他样本在决策边界附近发生变化，概率差也可能影响融合。开发—测试成绩变化同时包含样本及计算后端因素。
- 状态：**原文已披露的风险，准入范围已补清。** 当前不据此认定测试数字错误，也未声称逐位等价。

### M8 可靠性曲线裁掉了一个实际存在的非空分箱点

- 状态：**已将纵轴下限调整为 0，完整显示全部非空分箱。** 原分箱边界、样本数、曲线数据、概率及 ECE 不变。
